
# To do list

An interactive **ToDo List application** built with **React (Vite)** on the frontend, **Node.js + Express** on the backend, and **MySQL** as the database.  
It features **smooth animations with Tailwind CSS** and a **full REST API** for task management.

---

## 🚀 Features

- ✏ **Add, edit, and delete tasks** easily.
- 🎨 **Tailwind animations** for a modern and smooth UI experience.
- 🔄 **Full REST API** built with Node.js and Express.
- 🗄 **MySQL database** for persistent storage of tasks.
- ⚡ **React + Vite** for a fast development and build process.

---

## 🛠 Tech Stack

**Frontend:**
- [React (Vite)](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Axios](https://axios-http.com/) *(for API requests)*

**Backend:**
- [Node.js](https://nodejs.org/)
- [Express](https://expressjs.com/)
- [MySQL](https://www.mysql.com/)

---

Full REST API application development, with Node and React-Vite

Important:
To make it work you must configure a database in MySQL corresponding to the mysql.js file found in the "server" folder.
